# Ember Offline shared

Deze map is bedoeld voor logica die we bewust tussen online Ember en Ember Offline willen delen.

Kandidaat-onderdelen:

- runner utilities;
- survey-model helpers;
- validatie die geen online afhankelijkheden heeft;
- package readers en mappers;
- lokale statushelpers.

Belangrijke regel:

- alleen echt gedeelde logica hierheen verplaatsen;
- geen offline-only of online-only code kunstmatig samenpersen.
